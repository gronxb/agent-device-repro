# agent-device-repro

Runnable reproductions for [agent-device](https://github.com/callstack/agent-device) issues.
Each reproduction lives on its own branch.

| Branch | Issue | Platform |
| --- | --- | --- |
| [`ios-edge-swipe`](https://github.com/gronxb/agent-device-repro/tree/ios-edge-swipe) | [callstack/agent-device#4208](https://github.com/callstack/agent-device/issues/4208) | iOS simulator |
| [`ios-unavailable-device`](https://github.com/gronxb/agent-device-repro/tree/ios-unavailable-device) | [callstack/agent-device#4209](https://github.com/callstack/agent-device/issues/4209) | iOS physical device |

```sh
git clone -b <branch> https://github.com/gronxb/agent-device-repro.git
```

Each branch has a README with the run command and the expected output.
